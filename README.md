# dcr-t98-web
`dcr-t98`のブラウザ完結版です。RTL-SDR制御は`webrtlsdr`、AMBE+2のエンコード及びデコードは`blip25-vocoder`を使用しています。送信用ファイル生成にも対応しています。RTL-SDRからの入力とIQファイルからの入力に対応しています。RTL-SDR以外のSDRは対応していません。

## 動作環境
- RTL-SDR ドングル
- Node.js / npm
- Rust / wasm-pack
- Git
- WebUSBが動作するブラウザ
- ファイルシステムAPIが動作するブラウザ（必須ではない）

使用するブラウザがファイルシステムAPIに対応していない場合、**256MB**を超えるファイルはダウンロードできません。（出力サンプルレート2MHzで**約1分**エンコードすると超えます）<br>`WinUSB`などのSDRが動作するUSBドライバーがインストールされているか確認してください。

## インストール
```
# リポジトリをクローン
git clone https://github.com/c00380/dcr-t98-web.git
cd dcr-t98-web

# ビルド・実行
npm run setup
npm start
```
`blip25-vocoder`のクローン時に特許及び出典に関する注意事項がダウンロードされ、その内容を了承するかどうかを聞かれます。**文章をよく読んだうえで**判断してください。

## 使い方
`npm start`をコマンドラインで実行するか、`webui.bat`を実行します。`http://localhost:8973`でhttpサーバーが起動します。SDRを他のプログラムが使用していないか確認してください。

### スキャンモード
指定したバンドの全チャンネルをスキャンします。信号が確認できた場合音声デコードも行います。

### 固定モード
特定の1チャンネルまたは指定した周波数で受信します。

### ファイルモード
IQファイルからデコードします。`8-bit int/16-bit int/32-bit float`に対応しています。

### 送信モード
送信用のIQファイルを音声ファイルから生成します。このモードに送信機能はありません。

## 制限
- RALCWI 方式機は非対応（ソフトウェアコーデックが存在しません）。
- 秘話解読は音声が流れているフレームが必要です（無音のみでは判定不可）。
