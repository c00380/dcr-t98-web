# dcr-t98-web
`dcr-t98`のブラウザ完結版です。RTL-SDR制御は`webrtlsdr`、AMBE+2のエンコード及びデコードは`blip25-vocoder`を使用しています。送信用ファイル生成にも対応しています。RTL-SDRからの入力とIQファイルからの入力に対応しています。

## 動作環境
- RTL-SDR ドングル
- NodeJS
- WebUSBが動作するブラウザ
- ファイルシステムAPIが動作するブラウザ（必須ではない）

## インストール
```
# リポジトリをクローン
# 特許などについての告知事項を理解したうえで続行してください
git clone https://github.com/c00380/dcr-t98-web.git
cd dcr-t98-web

# ビルド・実行
npm run setup
npm start
```

## 使い方
`npm start`をコマンドラインで実行するか、`webui.bat`を実行します。`http://localhost:8973`でhttpサーバーが起動します。

### スキャンモード
指定したバンドの全チャンネルをスキャンします。信号が確認できた場合音声デコードも行います。

### 固定モード
特定の1chまたは指定した周波数で受信します。

### ファイルモード
IQファイルからデコードします。`8bit int/16bit int/32bit float`に対応しています。

### 送信モード
送信用のIQファイルを音声ファイルから生成します。このモードに送信機能はありません。
